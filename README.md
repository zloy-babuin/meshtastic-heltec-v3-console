# meshtui

Консольный (TUI) клиент для нод [Meshtastic](https://meshtastic.org). Подключается по USB (serial) или по TCP/Wi‑Fi. Работает в Linux, macOS и Windows: нужен Python 3.10+ и терминал с поддержкой цвета (в Windows — Windows Terminal).

## Возможности

| Вкладка | Что делает |
|---|---|
| **Чат** `F1` | входящие сообщения каналов и личные; отправка в канал или конкретному узлу; статус доставки (ACK / ретранслятор / ошибка); счётчик байт (лимит 233) |
| **Узлы** `F2` | список узлов: имя, ID, модель, SNR, хопы, питание, когда слышали. `Enter` на строке — написать узлу лично |
| **Эфир** `F3` | журнал всех принятых пакетов: тип, содержимое, SNR/RSSI, хопы |
| **Устройство** `F4` | сводка по ноде, смена имени, синхронизация времени с ПК, перезагрузка, выключение |
| **Настройки** `F5` | все секции конфигурации (`device`, `lora`, `display`, …) и модулей (`mqtt`, `telemetry`, …). Форма строится автоматически по protobuf-схеме, перед записью показывается список изменений |

Время ноды выставляется при каждом подключении: у многих плат (например, Heltec V3) нет батарейки часов. Если нода перезагрузилась, клиент переподключится сам.

## Установка

```bash
# из каталога проекта
pipx install .            # команда meshtui появится в PATH
# или в виртуальное окружение
python -m venv .venv
.venv/bin/pip install -e .       # Windows: .venv\Scripts\pip install -e .
```

## Запуск

```bash
meshtui                       # автопоиск USB-порта
meshtui -p /dev/ttyUSB0       # Linux
meshtui -p COM3               # Windows
meshtui -p /dev/cu.usbserial-0001   # macOS
meshtui --host 192.168.1.50   # по Wi‑Fi/TCP
meshtui --list-ports          # какие порты найдены
meshtui --no-time-sync        # не трогать время ноды
meshtui --log debug.log       # отладочный лог библиотеки meshtastic
```

Если кабель выдернуть и вставить снова, клиент переподключится сам через пару секунд. Без `-p` порт каждый раз ищется заново, так что смена `ttyUSB0` → `ttyUSB1` или `COM3` → `COM5` не мешает. С явным `-p` клиент ждёт именно этот порт. В Linux для этого удобен постоянный путь из `/dev/serial/by-id/`, он не зависит от порядка подключения устройств.

Клавиши: `F1`–`F5` — вкладки, `Tab` — переход между полями, `Ctrl+Q` — выход, `Ctrl+P` — палитра команд.

## Доступ к порту

- **Linux**: пользователь должен состоять в группе `dialout` (`sudo usermod -aG dialout $USER` и перелогиниться).
- **Windows / macOS**: для плат на CP210x или CH340 может понадобиться драйвер производителя моста.
- Порт занимает только одна программа: закрой приложение Meshtastic, веб-клиент или `meshtastic` CLI, если они подключены к той же ноде.

## Устройство кода

- `meshtui/radio.py` — обёртка над библиотекой `meshtastic`: подключение, события, команды.
- `meshtui/config_form.py` — форма секции настроек по protobuf-дескриптору.
- `meshtui/app.py` — приложение на [Textual](https://textual.textualize.io).
